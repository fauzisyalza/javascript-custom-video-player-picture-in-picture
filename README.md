# 🎬 JavaScript Custom Video Player with Picture-in-Picture

A custom video player without default browser controls, featuring Play, Pause, and Minimize (Picture-in-Picture) buttons.

### ✨ Features
- Custom Play / Pause buttons
- Minimize button using Picture-in-Picture API
- Video control with JavaScript `video.play()`, `video.pause()`, `requestPictureInPicture()`
- Custom UI built with CSS, no default `controls`

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)

### 🚀 How to Use
1. Click `PLAY` to start the video
2. Click `PAUSE` to pause the video
3. Click `MINIMIZE` to watch the video while browsing other tabs (Picture-in-Picture)
